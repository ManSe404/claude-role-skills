# Parcel booking v2: design

Design documents for the next version of parcel booking at Acme Logistics.
There is no code yet: the design is reviewed before the teams start to build.

- `design/proposal.md`: the proposal, with the components, flows, data ownership and rollout.
- `design/quality-goals.md`: the quality goals the design must meet.
- `design/adr/`: the architecture decision records.
